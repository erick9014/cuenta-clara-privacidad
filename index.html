Politica de privacidad de CUENTA CLARA

Ultima actualizacion: 29 de mayo de 2026

CUENTA CLARA es una aplicacion creada por Ing. Heriberto Hernandez Rodriguez para ayudar a contribuyentes en Cuba a organizar informacion fiscal y realizar calculos estimados basados en el vector fiscal que el usuario decide importar.

Aviso: CUENTA CLARA no es una aplicacion oficial de ONAT. Los calculos son estimados y deben validarse con ONAT o con un asesor fiscal antes de realizar pagos, declaraciones o decisiones oficiales.

Datos que procesa la aplicacion

La aplicacion permite que el usuario introduzca o importe informacion como ingresos, gastos, trabajadores, carnet de identidad del trabajador, salarios, nomina mensual, fechas de pago, datos del vector fiscal, estados de cuenta PDF, configuracion fiscal, observaciones, respaldos y documentos PDF seleccionados manualmente por el usuario.

Almacenamiento de datos

Los datos se guardan localmente en el dispositivo mediante una base de datos SQLite de la propia aplicacion. La aplicacion no envia esta informacion al desarrollador ni a servidores externos.

Internet, publicidad y analiticas

La version Android actual no declara permiso de Internet, no usa publicidad, no usa SDKs de analiticas y no comparte datos con terceros.

Archivos PDF, CSV y respaldos

El usuario puede seleccionar PDFs mediante el selector de archivos de Android y puede guardar reportes, CSV, PDFs o respaldos en una ubicacion elegida por el usuario. Los respaldos se cifran localmente cuando el usuario decide crearlos.

Seguridad local

La aplicacion puede usar el bloqueo del dispositivo, biometria disponible, PIN interno opcional y respaldos cifrados para proteger el acceso local. Estas medidas no sustituyen las practicas de seguridad del propio usuario sobre su telefono.

Eliminacion de datos

El usuario puede eliminar sus datos desde las opciones internas de la aplicacion, borrando los datos de la app desde Ajustes de Android o desinstalando la aplicacion.

Menores de edad

CUENTA CLARA esta orientada a usuarios que gestionan informacion fiscal. No esta dirigida a menores de edad.

Cambios a esta politica

Esta politica puede actualizarse si la aplicacion cambia su funcionamiento. La version publicada debe reflejar siempre el comportamiento real de la aplicacion.
